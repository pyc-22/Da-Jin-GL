# 门店操作手册

## 前台收银员

1. **登录**：打开收银台，输入账号密码；退出点击右上角退出。顶部灯显示在线/离线。
2. **销售开单**：扫码枪直接扫描条码，或在搜索框输入名称/条码；点击商品加入清单。按克商品按当前金价×克重计价，按件商品使用售价，标签价使用商品标签价。输入工费，调整数量和折扣；删除商品使用行末删除按钮。
3. **旧金抵扣**：点击旧金抵扣，逐件录入克重、成色，继续添加多件；系统按克重×成色×回收金价汇总抵扣。
4. **结算**：核对应收金额，选择现金、微信、支付宝、银行卡或储值；组合支付时分别输入金额，差额为 0 后点击结算。
5. **打印**：结算后预览并打印 58/80mm 小票和 A4 质保单；历史单据可补打，系统记录补打日志。设备设置可修改打印机、纸宽和静默打印。
6. **以旧换新**：新商品加入清单后打开旧金抵扣，录入旧料明细；正差价收取差额，负差价提交审批，通过后结算。
7. **旧料回收**：录入验金克重、成色和扣损，系统计算金额；超过配置限额提交店长审批，通过后选择付款方式完成。
8. **盘点**：进入盘点，扫码录入实盘数量，查看差异并提交审批。
9. **会员**：在会员面板搜索手机号，或快速新建会员档案。
10. **交班**：打开交班对账，按支付方式核对系统金额，输入实点现金；有差异时先复核，再确认并打印交班单。
11. **单据**：按日期、状态或支付方式查询历史订单，打开详情查看明细并补打。
12. **断网**：离线灯亮起后仍可开单、结算和打印；订单保存在本地队列，网络恢复自动同步。出现冲突时按界面比较本地与云端版本后选择保留版本。

## 店长（管理端 + 手机端）

管理端登录后可查看仪表盘 KPI、7 日趋势和库存预警。审批中心查看价格、退货、回收、盘点申请，详情页填写意见后通过或驳回。金价页编辑足金、18K、铂金、银等价格并查看历史。库存页进行采购入库、销售出库查询、盘点和旧料查看。会员页查看消费与储值记录；人员页维护员工、角色和排班；报表页切换日报/月报、收银明细、毛利并导出 Excel；系统页维护门店、折扣阈值、大额回收限额、支付渠道、日志和打印模板。

手机端店长 Tab：看板、审批、报表、会员。看板显示营业额、订单、克重、回收和排行；审批 Tab 支持实时角标和移动审批；报表 Tab 查看趋势、品类占比和回收统计；会员 Tab 查看全店会员。个人中心可修改密码、消息设置和退出。

## 销售（手机端）

登录后底部 Tab 为会员、回访、开单、业绩。会员页搜索我的会员，公海池可认领未分配会员；详情查看消费、余额和标签。回访页拨号、填写记录、设置下次跟进时间并完成任务。移动开单选择会员、扫码商品、录入工费和折扣后提交到前台结算。业绩页查看销售额、单数、客单价、提成和排行；活动案例页浏览话术、方案并收藏。销售只能看到自己负责的会员和个人业绩。

## 系统管理员

在角色权限页新增角色并勾选权限码；用户页新增/禁用账号、分配角色和门店；分类页维护商品树；打印模板页预览小票、质保单、回收单；支付渠道页启停渠道和调整排序；日志页按模块、用户、时间追溯操作；备份页发起手动备份，服务器脚本执行恢复；系统参数页维护折扣阈值、回收限额、提成比例和金价类型。

## FAQ

1. **忘记密码？** 联系管理员重置后重新登录。
2. **登录提示账号禁用？** 管理员在用户页启用账号。
3. **商品搜不到？** 检查条码、状态和当前门店。
4. **扫码无反应？** 确认扫码枪以键盘模式输出并聚焦搜索框。
5. **金额不对？** 核对金价、克重、工费、数量和折扣。
6. **折扣低于阈值？** 等待店长审批通过后再结算。
7. **组合支付差额不为零？** 调整各渠道金额直到差额为 0。
8. **储值余额不足？** 先在会员详情充值或改用其他支付方式。
9. **小票乱码？** 安装正确驱动并选择对应编码/打印机。
10. **小票不出纸？** 检查纸卷方向、打印队列和纸宽设置。
11. **质保单无图片？** 检查商品图片 URL 和 MinIO 服务。
12. **订单提交失败？** 查看提示，确认库存和网络后重试。
13. **离线能否开单？** 收银台支持，手机端离线仅允许查看缓存。
14. **离线订单何时同步？** 网络恢复且前台保持运行时自动同步。
15. **出现同步冲突怎么办？** 对比字段后选择本地或云端版本并提交。
16. **金价未刷新？** 检查 WebSocket、Token 和后端状态后刷新页面。
17. **审批没有通知？** 检查手机网络和通知未读列表。
18. **库存变负数？** 后端会拒绝超库存订单，先做入库或盘点。
19. **会员重复？** 手机号是门店唯一键，使用原档案编辑。
20. **如何导出报表？** 在报表页设置筛选后点击导出 Excel。
21. **交班差异如何处理？** 复核现金、退款和未结算单，备注后提交店长。
22. **如何补打？** 单据查询打开详情，点击补打并选择打印机。
23. **如何修改门店名？** 管理员在系统设置修改并保存。
24. **如何增加支付方式？** 管理员在支付渠道页新增并启用。
25. **备份文件在哪里？** 项目根目录 `backup`，文件为 `.sql.gz`。
26. **恢复是否覆盖当前数据？** 恢复前脚本会自动生成当前库备份。
27. **管理端 403？** 当前角色没有该权限，联系管理员调整 RBAC。
28. **页面打不开？** 检查 Nginx、backend healthy 状态和浏览器地址。
