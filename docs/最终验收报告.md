## 部署验收

- 已执行 `docker compose up -d --build`，mysql、redis、minio、backend、admin-web 均 healthy；初始化容器成功创建 bucket 后正常退出。
- 管理端 `http://localhost` HTTP 200；MinIO `http://localhost:9001` HTTP 200；后端健康接口返回 `UP`。
- 空库脚本自动创建 26 张表，默认门店、4 角色、4 演示账号、6 支付渠道和系统阈值均存在。
- admin/admin 登录返回 JWT，金价接口鉴权访问成功。

- Electron 安装包已生成，H5 产物已生成。Compose 使用 bind volume 持久化 MySQL、Redis、MinIO、上传文件和备份。

## 已知限制与后续建议

1. Windows 安装器已生成，需在实际门店电脑完成一次双击安装和真实打印机冒烟测试。
2. ESC/POS 已覆盖通用 58/80mm 指令，不同厂商切纸、钱箱指令需现场校准。
3. MinIO 首次启动需要拉取镜像，生产环境应更换默认账号密码并配置 HTTPS。
4. 排班拖拽、加工调拨的复杂业务规则保留基础界面/API，建议在多门店上线前补充审批细则。
5. 后续可扩展多门店/加盟、线上商城、会员小程序、电子发票和更细粒度审计。
