# 接口文档

基础地址：`http://host:8080`（经管理端访问时为 `/api`）。除登录外均需 `Authorization: Bearer {token}`。统一响应：`{"code":200,"message":"success","data":...}`；参数校验错误 400，未登录 401，无权限 403，资源不存在 404，幂等/库存冲突 409，服务器错误 500。

## 认证

|接口|方法|参数|鉴权|
|---|---|---|---|
|登录|POST `/api/auth/login`|JSON `username`、`password` 必填|否|
|退出|POST `/api/auth/logout`|无|是|

成功示例：`{"code":200,"data":{"user":{"user_id":1,"role_code":"ADMIN"},"token":"JWT"}}`。

## 商品与分类

|接口|方法|参数|
|---|---|---|
|商品分页|GET `/api/goods/list`|`page`、`size`；`keyword`、`categoryId`、`priceType`、`status` 可选|
|扫码商品|GET `/api/goods/scan/{barcode}`|路径 `barcode` 必填|
|新增商品|POST `/api/goods`|`barcode`、`name`、`categoryId`、`priceType` 必填；`weight`、`costPrice`、`salePrice`、`stock`、`images` 可选|
|修改商品|PUT `/api/goods/{id}`|路径 `id`；同新增商品字段|
|分类列表|GET `/api/admin/categories`|无|
|新增分类|POST `/api/admin/categories`|`name`、`parentId`、`sort`|
|修改分类|PUT `/api/admin/categories/{id}`|路径 `id`，分类字段|
|删除分类|DELETE `/api/admin/categories/{id}`|路径 `id`|

商品分页返回 `data.records`、`data.total`；写操作返回 `data:null`。

## 金价、订单与支付

|接口|方法|参数|
|---|---|---|
|当前金价|GET `/api/gold-price/current`|无|
|保存金价|POST `/api/gold-price`|`priceType`、`price` 必填|
|金价历史|GET `/api/gold-price/history`|`days` 可选，默认 30|
|创建订单|POST `/api/order/create`|`items`、`clientRequestId` 必填；按单件扫码时 item 传 `pieceNos[]`，其长度必须等于 `qty`|
|订单详情|GET `/api/order/{id}`|路径 `id`|
|订单分页|GET `/api/order/list`|`page`、`size`；`status` 可选|
|退单申请|POST `/api/order/refund`|`orderId`、`reason`|
|收款记账|POST `/api/pay/pay`|`orderId`、`amount`、`payMethod` 或 `payments[]`|
|支付渠道|GET `/api/pay/methods`|无|
|渠道管理|GET `/api/pay/channels`；POST/PUT/DELETE `/api/pay/channels...`|渠道名称、编码、排序、状态、图标|

订单 item 字段：`goodsId`、`itemName`、`weight`、`unitPrice`、`laborFee`、`qty`、`subtotal`、`pieceNos[]`。创建订单使用 `clientRequestId` 唯一去重；传单件码时后端校验其属于当前门店、所属商品一致且在库，收款时再次原子校验并扣减指定实物。

## 回收、以旧换新、库存

|接口|方法|参数|
|---|---|---|
|创建回收单|POST `/api/recycle/create`|`weight`、`purity`、`deductLoss`、`totalAmount`、`payMethod`、`memberId`|
|回收列表|GET `/api/recycle/list`|无|
|创建换新单|POST `/api/trade-in/create`|`oldMaterialInfo`、`newGoodsInfo`、`diffAmount`、`memberId`|
|入库扫码查商品|GET `/api/stock/goods`|`barcode` 商品条码；可选 `pieceNo`，如已登记则拦截重复入库|
|单件码查实物|GET `/api/stock/piece`|`pieceNo` 必填，返回该实物及所属商品；仅返回当前门店数据|
|移动盘点入库|POST `/api/stock/stock-in`|item 可传 `pieceNo`/`pieceNos[]`；门店内单件码永久唯一|
|库存入库|POST `/api/stock/in`|`goodsId`、`qty`、`cost`、`billNo`、`type`|
|库存出库|POST `/api/stock/out`|`goodsId`、`qty`、`billNo`、`reason`；指定实物时传 `pieceNo` 且 `qty=1`|
|加工入库/出库|POST `/api/stock/process-in`、`/process-out`|库存移动字段|
|盘点提交|POST `/api/stock/check`|`billNo`、`totalDiff`|
|旧料库存|GET `/api/stock/old-material`|无|

## 会员、审批、回访

|接口|方法|参数|
|---|---|---|
|会员分页|GET `/api/member/list`|`page`、`size`、`keyword`|
|会员详情|GET `/api/member/{id}`|路径 `id`|
|消费记录|GET `/api/member/{id}/consume`|路径 `id`|
|新增会员|POST `/api/member`|`name`、合法手机号 `phone` 必填；`tags`、`salesId`、`birthday`、`source` 可选|
|公海池|GET `/api/member/pool`|`page`、`size`、`keyword`|
|认领/分配|POST `/api/member/{id}/claim`；POST `/assign`|分配接口 JSON `salesId`|
|储值充值/扣款|POST `/api/member/{id}/balance`|`amount`、`type=RECHARGE/DEDUCT`|
|储值记录|GET `/api/member/{id}/balance-records`|路径 `id`|
|待审批|GET `/api/approval/pending`|无（管理员/店长）|
|审批详情|GET `/api/approval/{id}`|路径 `id`|
|通过/驳回|POST `/api/approval/{id}/approve`、`/reject`|JSON `remark`/`reason`|
|回访任务|GET `/api/visit/tasks`；POST `/api/visit/tasks`|任务创建字段 `memberId`、`visitType`、`planTime`|
|保存回访|POST `/api/visit/record` 或 `/complete`|`taskId`、`record`、`nextTime`|
|通知列表|GET `/api/notification`|无|
|通知已读|POST `/api/notification/{id}/read`|路径 `id`|

|---|---|---|
|待打印任务|GET `/api/processing/print-jobs?status=PENDING`|按当前门店读取；状态支持 `PENDING/PRINTED/IGNORED`|
|确认已打印|POST `/api/processing/print-jobs/{jobId}/done`|记录打印时间与操作人|
|忽略打印任务|POST `/api/processing/print-jobs/{jobId}/ignore`|独立记录为 `IGNORED`，不冒充已打印|
|损耗汇总|GET `/api/processing/loss-summary`|参数 `from/to`；负损耗不计入正常汇总并返回异常数|
|损耗明细|GET `/api/processing/loss-orders`|参数 `craftsmanId/from/to/onlyOver/anomalies`|
|图片上传|POST `/api/upload`|multipart：`file`，可选 `bizType/orderNo`；按真实文件头识别图片格式|

## WebSocket 与同步

连接：`ws://host:8080/ws?token=JWT`。服务端消息示例：`{"type":"GOLD_PRICE_UPDATED","data":{"priceType":"足金","price":666}}`、`APPROVAL_UPDATED`、`MOBILE_ORDER_CREATED`。JWT 无效时拒绝连接。离线订单必须携带客户端生成的 `clientRequestId`；服务端以门店+该键唯一约束去重，版本冲突返回 409 并写入冲突记录，客户端展示本地/云端版本供人工合并。
