# 服务器配置快速指南

## 一、准备服务器

- 推荐 Ubuntu 22.04/24.04，4 核 CPU、8 GB 内存、100 GB SSD。
- 安装 Docker Engine 与 Docker Compose 插件。
- 准备域名时建议使用 `admin.example.com`（管理端）与 `m.example.com`（移动端）。

## 二、上传并启动

```bash
unzip 打金店管理系统-V1.0.0-rc.1.zip
cd 打金店管理系统-V1.0.0-rc.1/server
cp .env.production.example .env
nano .env
chmod +x backup.sh restore.sh
docker compose up -d --build
docker compose ps
```

`.env` 中所有 `CHANGE_ME` 必须替换。可用以下命令生成随机密码：

```bash
openssl rand -base64 32
```

没有域名时，将 `MINIO_CORS_ORIGINS` 设置为：

```text
http://服务器IP,http://服务器IP:81
```

## 三、访问地址

- 管理端：`http://服务器IP/`
- 移动端 H5：`http://服务器IP:81/`
- 后端健康检查：`http://服务器IP:8080/actuator/health`
- MinIO 控制台：`http://服务器IP:9001/`，仅在运维网络开放。

首次管理员由 `.env` 中的 `BOOTSTRAP_ADMIN_USERNAME`、`BOOTSTRAP_ADMIN_PASSWORD` 和 `BOOTSTRAP_ADMIN_NAME` 创建。登录成功后清空 `.env` 中的初始化密码，执行 `docker compose up -d backend`，再创建每位员工自己的账号和权限。

## 四、收银端

在 Windows 收银电脑安装 `cashier/打金店收银台 Setup 1.0.0-rc.1.exe`。首次启动进入设置：

- 同一局域网：API 地址填管理端网关 `http://服务器内网IP`。
- 已配置 HTTPS 域名：API 地址填 `https://admin.example.com`。
- 选择实际打印机名称、58/80mm 纸宽，并先关闭静默打印做一次预览测试。

## 五、安全组和防火墙

公网开放 `80/443`，测试移动端端口时额外开放 `81`。`3306/6379/9000/9001/8080` 不对公网开放；后端、MinIO 控制台默认只绑定服务器回环地址。

正式使用 HTTPS 后，用 Nginx、Caddy 或宝塔把两个域名分别反向代理到 `127.0.0.1:80` 和 `127.0.0.1:81`，并启用 WebSocket Upgrade。然后把 `MINIO_CORS_ORIGINS` 更新为两个 HTTPS 域名并执行：

```bash
docker compose up -d
```

## 六、备份

手动备份：

```bash
./backup.sh
```

每日凌晨 2 点自动备份：

```bash
crontab -e
0 2 * * * cd /opt/dajin/server && ./backup.sh >> backup/cron.log 2>&1
```

备份文件默认保留 30 天。恢复前执行：

```bash
./restore.sh backup/dajin_backup_YYYYMMDD_HHmmss.sql.gz
```

## 七、上线检查

```bash
docker compose ps
curl http://127.0.0.1:8080/actuator/health
docker compose logs --tail=100 backend
```

依次验证登录、图片上传、扫码入库、移动开单转收银、库存扣减、会员同步、价格实时同步、审批、打印和备份恢复。
