# 一、老板已确认的口径（先做这个，两条）

## 1. 回收屑：**不含补金** → 现状是对的，**不要改** ✅

- **现状**：回收屑 = 融后金重（来料加热融化后称的克重）− 成品金重，**没有用补金**。
- **期望**：**保持现状**（老板原话："根本用不到补金"）。**不要把补金加进回收屑公式**。

## 2. 损耗率的分母：**要含补金** → 这条要改 ✗

- **现状**：损耗率的分母现在是「来料折重 + 下料」。
- **期望**：分母改成 **「融后金重 + 补金」**：
  - **有补金**：损耗率 = 损耗 ÷（**融后金重 + 补金**）；
  - **没有补金**：损耗率 = 损耗 ÷ **融后金重**（补金为 0 时自然就是它，用同一个公式即可）；
  - 老板原话："有补金 损耗率 = 0.2 ÷（融后金重 + 补金）；没有补金的话 损耗率 = 0.2 ÷ 融后金重"。
  - ⚠️ 现在的公式里有"下料"这一项，老板这次没提它 —— **先按老板原话改（分母只保留融后金重 + 补金）**，并在汇报里**单独说明"下料"被去掉了**，让老板确认；不要自己发明。
- **举例**：打磨损耗 0.2g、融后金重 20g、补金 1g → 损耗率 = 0.2 ÷ 21 ≈ **9.52‰**；没有补金时 = 0.2 ÷ 20 = **10‰**。
- **验收**：造一单带补金、一单不带补金，核对损耗千分比；补/改单测。

# 二、第二组：剩余 4 条（都是"现在能用但不安全"的问题）

## 3. 客户照片不用登录就能看

- **现状**：系统存客户照片用的是公开网址；**别人拿到网址，不登录也能打开**（浏览器直接输入就能看）。
- **期望**：**必须登录才能看**，并按角色限定范围（与加工单/销售单**同一套归属规则**）：
  - **管理员 / 店长 / 收银员** → **本店全部**单据照片（收银员要在柜面核对取货照片，不能只给她看"自己开的"）；
  - **销售** → **自己开的 或 挂在自己名下的**单（**不要收紧成只看开单人**）；
  - **打金师傅** → **派给自己的**单（`craftsman_id` = 自己）；
  - 取货 / 称重 / 来料照片都算；**打印与质保单复用同一套校验**。

## 4. 新增员工的默认密码是 `admin`

- **现状**：管理端新增员工时如果没填密码，系统默认给 `admin`；密码在数据库里还是**明文**存的。
- **期望**：新增员工**必须设置密码**（不能默认 `admin`，也不能空）；密码要**加密存储**；登录只认加密后的比对。

## 5. 单号用"毫秒"生成，可能重复

- **现状**：好几处单号是「类型 + 当前毫秒」拼的，**一毫秒内两笔操作可能撞出同一个单号**（回收、入库、手工入库、交班都有）。
- **期望**：单号**唯一、不重复**（并发也不会撞）；格式保持现在的前缀+可读日期即可；数据库层面加唯一约束兜底。

## 6. 质保单上的门店地址写死了

- **现状**：质保单底部门店地址是**写死在程序里的**（河南省郑州市中原区绿东村街道华山路155-3号阳光商务二楼鑫铖金匠），不是从"门店设置"读的。
- **期望**：门店名称、地址、电话都**从门店设置读取**；换地址或开分店时打印内容跟着变；设置里没填时留空而不是印错地址。
