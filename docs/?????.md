# 数据库文档

数据库：MySQL 8.0，字符集 `utf8mb4`，排序规则 `utf8mb4_unicode_ci`，存储引擎 InnoDB。当前 `db/schema.sql` 定义 38 张物理表；所有表均含 `store_id`，业务主键使用语义化命名。字段变更以 `db/schema.sql` 和 `SchemaCompatibilityMigration` 为准。

字段记法：`字段 类型 [必填] [默认] - 说明`。

## 表定义

### sys_store（门店）
`store_id BIGINT PK`；`store_name VARCHAR(100) 必填`；`address VARCHAR(255)`；`phone VARCHAR(30)`；`logo VARCHAR(500)`；`status TINYINT 必填 默认1`；`create_time DATETIME 默认CURRENT_TIMESTAMP`；`update_time DATETIME 默认CURRENT_TIMESTAMP ON UPDATE`。索引：主键。

### sys_role（角色）
`role_id BIGINT PK AI`；`store_id BIGINT 必填`；`role_name VARCHAR(50) 必填`；`role_code VARCHAR(50) 必填`；`permissions JSON`；`status TINYINT 默认1`；`create_time DATETIME`；`update_time DATETIME`。索引：`uk_role_store_code(store_id,role_code)`。

### sys_user（用户）
`user_id BIGINT PK AI`；`store_id BIGINT 必填`；`username VARCHAR(64) 必填`；`password VARCHAR(255) 必填`；`real_name VARCHAR(50) 必填`；`role_id BIGINT 必填`；`phone VARCHAR(30)`；`id_card VARCHAR(32)`；`entry_date DATE`；`status TINYINT 默认1`；`create_time DATETIME`；`update_time DATETIME`；`version INT 默认0`。索引：`uk_user_store_username(store_id,username)`。

### goods_category（商品分类）
`category_id BIGINT PK AI`；`store_id BIGINT 必填`；`name VARCHAR(100) 必填`；`parent_id BIGINT 默认0`；`sort INT 默认0`；`status TINYINT 默认1`；`create_time DATETIME`；`update_time DATETIME`。索引：无额外索引。

### goods（商品）
`goods_id BIGINT PK AI`；`store_id BIGINT 必填`；`barcode VARCHAR(32) 必填`；`name VARCHAR(100) 必填`；`category_id BIGINT 必填`；`weight DECIMAL(10,3)`；`cost_price DECIMAL(12,2) 默认0`；`sale_price DECIMAL(12,2)`；`price_type TINYINT 必填`；`stock INT 默认0`；`images JSON`；`status TINYINT 默认1`；`create_time DATETIME`；`update_time DATETIME`；`version INT 默认0`。索引：`uk_goods_store_barcode`、`idx_goods_category(store_id,category_id)`。

### goods_piece（单件实物）
`piece_id BIGINT PK AI`；`store_id BIGINT 必填`；`goods_id BIGINT 必填`；`piece_no VARCHAR(80) 必填`；`image TEXT`；`status TINYINT 默认1`；`inbound_id BIGINT`；`sales_order_id BIGINT`；`create_time/update_time DATETIME`。`piece_no` 是饰品实物身份，索引 `uk_goods_piece_store_no(store_id,piece_no)` 保证同一门店一物一码；`goods_id` 表示该实物所属商品档案。

### process_item（加工项目）
`process_id BIGINT PK AI`；`store_id BIGINT 必填`；`name VARCHAR(100) 必填`；`type VARCHAR(30)`；`base_fee DECIMAL(12,2) 默认0`；`process_steps JSON`；`duration INT`；`status TINYINT 默认1`；`create_time DATETIME`；`update_time DATETIME`。索引：无额外索引。

### gold_price（金价）
`price_id BIGINT PK AI`；`store_id BIGINT 必填`；`price_type VARCHAR(30) 必填`；`price DECIMAL(12,2) 必填`；`date DATE 必填`；`operator_id BIGINT`；`create_time DATETIME`。索引：`idx_gold_store_type_date(store_id,price_type,date,price_id)`。

### stock_in（入库单）
`stock_in_id BIGINT PK AI`；`store_id BIGINT 必填`；`bill_no VARCHAR(32) 必填`；`type VARCHAR(30) 必填`；`goods_id BIGINT`；`qty DECIMAL(12,3) 默认0`；`cost DECIMAL(12,2) 默认0`；`operator_id BIGINT`；`create_time DATETIME`。索引：`uk_stockin_store_bill`。

### stock_out（出库单）
`stock_out_id BIGINT PK AI`；`store_id BIGINT 必填`；`bill_no VARCHAR(32) 必填`；`type VARCHAR(30) 必填`；`goods_id BIGINT`；`qty DECIMAL(12,3) 默认0`；`reason VARCHAR(255)`；`operator_id BIGINT`；`create_time DATETIME`。索引：`uk_stockout_store_bill`。

### stock_check（盘点单）
`check_id BIGINT PK AI`；`store_id BIGINT 必填`；`bill_no VARCHAR(32) 必填`；`status TINYINT 默认1`；`total_diff DECIMAL(12,3) 默认0`；`operator_id BIGINT`；`approver_id BIGINT`；`approve_remark VARCHAR(500)`；`create_time DATETIME`；`update_time DATETIME`。索引：`uk_stockcheck_store_bill`。

### old_material（旧料）
`material_id BIGINT PK AI`；`store_id BIGINT 必填`；`material_type VARCHAR(50) 必填`；`weight DECIMAL(10,3) 必填`；`purity DECIMAL(6,4) 必填`；`source VARCHAR(100)`；`value DECIMAL(12,2) 默认0`；`status TINYINT 默认1`；`create_time DATETIME`；`update_time DATETIME`；`version INT 默认0`。索引：无额外索引。

### sales_order（销售订单）
`order_id BIGINT PK AI`；`store_id BIGINT 必填`；`order_no VARCHAR(32) 必填`；`member_id BIGINT`；`total_amount DECIMAL(12,2) 默认0`；`discount DECIMAL(5,2) 默认1`；`old_material_deduct DECIMAL(12,2) 默认0`；`labor_fee DECIMAL(12,2) 默认0`；`pay_amount DECIMAL(12,2) 默认0`；`pay_method VARCHAR(50)`；`cashier_id BIGINT`；`sales_id BIGINT`；`approval_id BIGINT`；`status TINYINT 默认3`；`remark VARCHAR(500)`；`client_request_id VARCHAR(64)`；`create_time DATETIME`；`update_time DATETIME`；`version INT 默认0`。索引：订单号和客户端请求唯一键，`idx_order_store_create(store_id,create_time)`。

### sales_order_item（订单明细）
`order_item_id BIGINT PK AI`；`store_id BIGINT 必填`；`order_id BIGINT 必填`；`goods_id BIGINT`；`item_name VARCHAR(100) 必填`；`weight DECIMAL(10,3)`；`unit_price DECIMAL(12,2) 默认0`；`labor_fee DECIMAL(12,2) 默认0`；`qty DECIMAL(12,3) 默认1`；`subtotal DECIMAL(12,2) 默认0`；`cost_snapshot DECIMAL(14,2)`；`piece_nos JSON`；`create_time DATETIME`。`piece_nos` 保存扫码选中的具体实物，收款出库及退款均按这些单件码处理。索引：`idx_order_item(store_id,order_id)`。

### recycle_order（回收单）
`recycle_order_id BIGINT PK AI`；`store_id BIGINT 必填`；`bill_no VARCHAR(32) 必填`；`member_id BIGINT`；`material_type VARCHAR(50)`；`weight DECIMAL(10,3) 必填`；`purity DECIMAL(6,4) 必填`；`deduct_loss DECIMAL(12,2) 默认0`；`total_amount DECIMAL(12,2) 默认0`；`pay_method VARCHAR(50)`；`status TINYINT 默认1`；`approver_id BIGINT`；`create_time DATETIME`；`update_time DATETIME`。索引：`uk_recycle_store_bill`。

### trade_in（以旧换新）
`trade_in_id BIGINT PK AI`；`store_id BIGINT 必填`；`bill_no VARCHAR(32) 必填`；`member_id BIGINT`；`old_material_info JSON`；`new_goods_info JSON`；`diff_amount DECIMAL(12,2) 默认0`；`status TINYINT 默认1`；`approval_id BIGINT`；`create_time DATETIME`；`update_time DATETIME`。索引：`uk_tradein_store_bill`。

### member（会员）
`member_id BIGINT PK AI`；`store_id BIGINT 必填`；`name VARCHAR(100) 必填`；`phone VARCHAR(30) 必填`；`tags JSON`；`balance DECIMAL(12,2) 默认0`；`points INT 默认0`；`total_consume DECIMAL(12,2) 默认0`；`source VARCHAR(50)`；`sales_id BIGINT`；`birthday DATE`；`create_time DATETIME`；`update_time DATETIME`。索引：手机号唯一键、`idx_member_phone(store_id,phone)`。

### member_consume（会员消费/储值流水）

### visit_task（回访任务）

### approval（审批）

### commission_rule（提成规则）
`rule_id BIGINT PK AI`；`store_id BIGINT 必填`；`type VARCHAR(30) 必填`；`rate DECIMAL(8,4) 默认0`；`condition JSON`；`description VARCHAR(500)`；`status TINYINT 默认1`；`create_time DATETIME`；`update_time DATETIME`。索引：无额外索引。

### sys_config（系统配置）

### pay_channel（支付渠道）
`channel_id BIGINT PK AI`；`store_id BIGINT 必填`；`channel_name VARCHAR(50) 必填`；`channel_code VARCHAR(50) 必填`；`sort INT 默认0`；`status TINYINT 默认1`；`icon VARCHAR(255)`；`create_time DATETIME`。索引：`uk_pay_channel_store_code`。

## 关系与初始化

`sales_order.order_id` 关联 `sales_order_item.order_id`、`member_consume.order_id`；订单的 `member_id/cashier_id/sales_id` 分别关联会员和用户。支付写入 `finance_record.related_bill_no=order_no`，库存扣减写入 `stock_out`，旧金写入 `old_material`。`approval.biz_id` 指向订单、回收单或盘点单，`trade_in.approval_id` 关联审批。

初始化：门店 `store_id=1 默认门店`；角色 ADMIN、MANAGER、CASHIER、SALES；账号均为演示密码 `admin`；支付渠道现金、微信、支付宝、银行卡、储值、组合；系统配置 `discount_threshold=0.85`、`recycle_approval_limit=10000`、`default_commission_rate=0.01`；预置商品、分类和足金/回收金价。
