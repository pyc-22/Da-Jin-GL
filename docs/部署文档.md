# 打金店管理系统部署文档

## 1. 架构

收银 Electron、管理端 Vue、手机端 H5/Uni-App 都通过 HTTPS/HTTP 调用 Spring Boot API；WebSocket 推送金价、审批和移动开单事件。Spring Boot 使用 MySQL 保存业务数据、Redis 保存缓存/会话，MinIO 保存图片，Nginx 托管管理端并代理 `/api`、`/uploads`。

## 2. 环境要求

服务器最低 2 核 CPU、4 GB RAM、50 GB SSD；生产建议 4 核 8 GB、Ubuntu 22.04/24.04。服务器安装 Docker Engine 与 Docker Compose 插件。收银电脑使用 Windows 10/11、8 GB RAM和 USB/网络打印机。推荐通用 ESC/POS 58/80mm 热敏机，质保单使用 A4 打印机。

## 3. Docker 部署

1. 从 GitHub 克隆源码并进入项目目录：`git clone GITHUB_REPOSITORY_URL dajin-system && cd dajin-system`。也可上传源码发布包并解压。
2. 执行 `cp .env.production.example .env`，修改数据库、Redis、MinIO 密码、`JWT_SECRET` 与 `BOOTSTRAP_ADMIN_*`；所有 `CHANGE_ME` 都必须替换。
3. 单 IP 测试时，把 `MINIO_CORS_ORIGINS` 设置为 `http://服务器IP,http://服务器IP:81`。使用域名时填写管理端和移动端的 HTTPS 地址，以英文逗号分隔。
4. 首次启动执行 `docker compose -f docker-compose.release.yml up -d --build`。MySQL 首次启动会自动执行 `db/schema.sql`。第一次构建后端会下载 Maven 依赖，后续构建使用 Docker 缓存。
5. 执行 `docker compose -f docker-compose.release.yml ps`，等待 mysql、redis、minio、backend、admin-web、mobile-web 全部为 `healthy`，`minio-init` 为 `Exited (0)`。
6. 管理端访问 `http://服务器IP/`，移动端 H5 访问 `http://服务器IP:81/`。首次管理员由 `BOOTSTRAP_ADMIN_*` 创建；登录成功后清空 `.env` 中的初始化密码并执行 `docker compose -f docker-compose.release.yml up -d backend`。
7. 防火墙只开放 `80/443/81`；`3306/6379/9000/9001/8080` 只允许服务器本机或内网访问。

## 4. 环境变量

|变量|说明|建议|
|---|---|---|
|MYSQL_ROOT_PASSWORD|MySQL root 密码|生产随机强密码|
|MYSQL_DATABASE|数据库名|dajin|
|MYSQL_USER/MYSQL_PASSWORD|应用账号密码|生产独立账号|
|REDIS_PASSWORD|Redis 密码|可设置强密码|
|MINIO_ROOT_USER/MINIO_ROOT_PASSWORD|MinIO 管理账号|生产修改|
|MINIO_BUCKET|图片 bucket|dajin-assets|
|MINIO_PUBLIC_ENDPOINT|MinIO 对外地址|通常留空，图片通过 `/api/file` 访问|
|MINIO_CORS_ORIGINS|允许访问的前端来源|填写管理端、移动端正式地址|
|JWT_SECRET|JWT 签名密钥|至少 32 字节随机值|
|JWT_EXPIRATION|Token 有效期（小时）|2|
|BACKEND_PORT/ADMIN_WEB_PORT/MOBILE_WEB_PORT|宿主机端口|8080/80/81|
|STORE_NAME|默认门店名称|默认门店|
|BOOTSTRAP_ADMIN_USERNAME|空库首次启动管理员账号|4-20 位字母数字|
|BOOTSTRAP_ADMIN_PASSWORD|空库首次启动管理员密码|10-72 位且含字母和数字，建号后从 `.env` 清空|
|BOOTSTRAP_ADMIN_NAME|首次管理员姓名|系统管理员|

## 5. 客户端

前台端：运行 `cashier/打金店收银台 Setup 1.0.0-rc.1.exe`，安装后首次启动输入 API 网关地址（例如 `http://192.168.1.100`），在设备设置选择打印机、58/80mm 和静默打印，随后登录。

管理端：浏览器访问 `http://服务器IP/`。

手机端：Docker 部署后访问 `http://服务器IP:81/`；也可用 HBuilderX 导入 `mobile`，配置 AppID 后云打包 Android/iOS，详见《手机端打包说明》。“添加到手机桌面”可作为 H5/PWA 使用，但扫码、相机和蓝牙打印等原生能力应使用 Android/iOS 安装包验证。

## 6. HTTPS 与域名

生产建议使用两个域名，例如 `admin.example.com`（管理端）和 `m.example.com`（移动端），由服务器上的 Caddy/Nginx/宝塔反向代理到 `127.0.0.1:80` 与 `127.0.0.1:81`。反向代理必须保留 `/ws` 的 WebSocket Upgrade 头。证书启用后，将 `.env` 中 `MINIO_CORS_ORIGINS` 改为 `https://admin.example.com,https://m.example.com`，然后执行 `docker compose up -d`。

## 7. 打印配置

安装 Windows 厂商驱动，确认“打印机和扫描仪”中的名称。前台设置选择该名称和纸宽；ESC/POS 自动生成初始化、居中、粗体、换行、切纸指令。静默打印关闭时先预览，开启时直接发送到系统打印队列。

## 8. 备份

手动备份：`pwsh -ExecutionPolicy Bypass -File .\backup.ps1`。文件写入 `backup/dajin_backup_YYYYMMDD_HHmmss.sql.gz`，默认保留 30 天。注册每日 02:00 任务：管理员 PowerShell 执行 `pwsh -ExecutionPolicy Bypass -File .\register-backup-task.ps1`。恢复执行 `restore.ps1`，选择文件并输入 `RESTORE` 确认。

## 9. 常见问题

|问题|原因与处理|
|---|---|
|服务启动失败|执行 `docker compose logs 服务名`；检查端口、`.env` 和磁盘空间后 `docker compose up -d --build`。|
|连接不上后端|确认 8080 端口、防火墙和 API 地址；容器内用 `curl http://backend:8080/actuator/health`。|
|打印机不打印|检查 Windows 队列、驱动名称、纸宽和 USB/网络连接；先关闭静默打印预览。|
|金价不更新|确认 WebSocket 使用 `/ws?token=JWT`，检查 Redis/后端日志并刷新登录。|
|断网订单未同步|恢复网络后保持前台运行，查看同步队列；冲突记录需人工选择版本。|
|图片上传失败|确认 MinIO healthy、bucket 存在及 `data/uploads` 可写。|
|登录失败|确认账号状态为启用，使用初始化密码并检查 API 返回错误信息。|

## 10. 上线验证

1. `curl http://127.0.0.1:8080/actuator/health` 返回 `UP`。
2. 管理端与移动端都能登录，上传一张商品图片后两端都能打开。
3. 管理端修改商品价格，收银端和移动端无需刷新即可收到更新。
4. 创建测试订单并在收银端结算，库存只扣减一次。
5. 重启容器后数据、图片仍存在：`docker compose restart` 后复查订单和图片。

## 11. 运维命令

- 启动：`docker compose -f docker-compose.release.yml up -d`
- 停止：`docker compose -f docker-compose.release.yml down`
- 查看状态：`docker compose -f docker-compose.release.yml ps`
- 后端日志：`docker compose -f docker-compose.release.yml logs -f backend`
- 重启后端：`docker compose -f docker-compose.release.yml restart backend`
- 进入数据库：`docker compose -f docker-compose.release.yml exec mysql mysql -uroot -p`
