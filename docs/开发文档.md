# 开发文档

## 项目结构

`backend/` Spring Boot 源码、控制器、配置和测试；`front-pc/` Electron 主进程、Vue 收银界面、SQLite/ESC-POS；`admin-web/` Vue3 管理端、路由、Pinia、API 模块；`mobile/` Uni-App/Vite H5、角色页面和移动 API；`db/schema.sql` 数据库结构及种子；`docker-compose.yml` 部署编排；`backup.ps1/restore.ps1` 运维脚本；`docs/` 交付文档。

## 技术栈

后端 Java 17、Spring Boot 2.7、MyBatis/JdbcTemplate、JWT、WebSocket、MySQL 8、Redis 6、MinIO；管理端/前台 Vue 3、Vite、Element Plus、Pinia、Axios、ECharts、xlsx、Electron；手机端 Uni-App/Vue3、uView Plus、Pinia、ECharts；测试 JUnit 5、Vitest。

## 核心设计

### 订单状态机

`待审批(2)`：折扣低于 `discount_threshold` 或负差价；`已审批(3)`：审批通过后可收款；`已完成(1)`：支付成功、库存扣减、财务流水写入；`已退单(4)`：退款审批通过并完成库存/财务反向流水。普通订单可直接进入已完成。

### 审批流程

订单折扣、负差价、大额回收、退货和盘点差异触发 `approval` 记录，状态为待审；管理员/店长通过或驳回并填写意见，WebSocket 推送业务端，审批结果写入关联单据。

### 库存流水

入库写 `stock_in`，销售/加工出库写 `stock_out`，盘点写 `stock_check`，旧金写 `old_material`。商品库存更新与流水在同一事务中完成，并使用版本/条件更新防止超卖。

### 离线同步

Electron 将商品、金价、会员缓存到本地 SQLite；离线订单、支付和打印任务写 `sync_queue`，每条带 `clientRequestId`。联网后按创建顺序上传，服务端唯一键幂等去重；库存或版本冲突写 `sync_conflict`，客户端显示差异并由收银员选择本地/云端版本。

### WebSocket

连接 `/ws?token=JWT`，服务端验证 JWT 后广播 `GOLD_PRICE_UPDATED`、`APPROVAL_UPDATED`、`MOBILE_ORDER_CREATED`。前端断线指数退避重连，重连后重新拉取当前金价和待办。

### RBAC

`sys_role.permissions` 保存权限码；角色映射菜单和按钮，后端 `@RequireRoles` 校验接口，前端 `v-permission` 控制按钮。ADMIN 全部权限，MANAGER 经营/审批权限，CASHIER 仅收银，SALES 仅个人会员/业绩。

### 提成

`commission_rule` 按业务类型保存比例或固定规则；订单完成后按销售额/毛利计算，结果写入 `commission_record`，报表按员工和月份汇总。

## 编码规范

Java 类名 PascalCase、方法和变量 camelCase，数据库字段 snake_case；Vue 组件 PascalCase、API 模块按业务命名。公共逻辑写简短注释；控制器统一返回 `ApiResponse`，参数使用 Bean Validation，异常交给全局处理器；金额使用 BigDecimal，所有 SQL 带 `store_id` 条件。

## 添加功能

后端：在对应模块新增 Controller/Service/Mapper，补充权限、事务、幂等键和测试，再更新接口文档。管理端：在 `src/api` 增加请求函数，在 `views` 增加页面并注册懒加载路由和菜单权限。手机端：在角色配置中声明页面和 Tab，新增 view、API 与缓存策略。涉及数据时先修改 schema 和数据库文档。

## 测试与构建

后端：`./mvnw -pl backend test`；管理端：`pnpm install && pnpm run test && pnpm run build`；前台端：`pnpm run test && pnpm run build`，安装包 `pnpm run dist`；手机端：`pnpm run test && pnpm run build:h5`。联调使用 Docker Compose，接口通过 Swagger 或 curl 验证。
