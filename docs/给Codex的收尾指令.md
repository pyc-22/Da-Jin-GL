## 为什么必须分三步（不要一次全塞）

1. **撞文件**：移动端清单的问题 2/7 和加工批次都要改 `mobile/src/views/ProcessingOrders.vue`、`front-pc/src/App.vue` ✗ → 并行改容易互相覆盖。
2. **第 1 步没收尾就做别的** → 半成品 + 端到端没做 → 出问题分不清是谁引入的 ✗。
3. **"最后一起检查"本来就是第 3 步** ✓ → 那时候它自己的两批 + 老板的改动都在，一次审完最划算 ✓。
