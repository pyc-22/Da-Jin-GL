# 打金店管理系统 V1.0.0-rc.1 发布说明

发布日期：2026-09-19

## 2026-09-20 收银端白屏修订

- 修复 Windows 安装版通过 `file://` 打开时，JS/CSS 使用 `/assets/...` 导致 `ERR_FILE_NOT_FOUND` 的问题。资源引用现为 `./assets/...`。
- Electron 的 `loadFile` 入口已核对正确：`app.asar/dist/index.html`。
- 已重新生成收银安装程序，并更新整套发布 ZIP 与 SHA-256 校验文件。版本号保持 `1.0.0-rc.1`，请用本次修订文件替换 2026-09-19 的收银安装程序。
- 收银端 30 项测试、构建资源路径检查及 Electron ASAR 页面启动检查均通过。此次验证范围为本地页面加载；服务器登录、收款、打印和容器健康仍按部署验收执行。

## 制品

- 服务端 Docker 部署包：Spring Boot、管理端 H5、移动端 H5、MySQL、Redis、MinIO。
- Windows x64 收银端 NSIS 安装包。
- 移动端 H5/PWA 独立压缩包。
- 部署、操作、接口、数据库、测试、回滚文档与 SHA-256 校验文件。

Android APK 不在本候选包内。当前移动端使用普通 Vite/Vue Router 构建，待 uni-app 原生构建链和扫码、相机、上传、拨号、后台恢复完成真机验收后单独发布签名 APK。

## 发布重点

- 销售默认权限包含入库盘点、回收、加工和会员；店长与销售继续按各自数据范围展示报表。
- 商品、库存、会员、金价、审批和打印任务通过 WebSocket 跨端同步。
- 盘点入库使用单件标识避免同一饰品重复入库，并保留手动入库、照片和离线草稿。
- 空库首次管理员通过服务器环境变量创建，密码以 BCrypt 保存；发布包不包含演示账号、演示商品或非零示例金价。
- MySQL、Redis、MinIO 和后端管理端口在发布 Compose 中限制为容器网络或服务器回环地址。

## 已知事项

- Windows 安装程序尚未配置商业代码签名证书，首次安装可能显示“未知发布者”。请先核对 `SHA256SUMS.txt`。
- Docker 运行验收需在已启动 Docker Engine 的服务器执行；本机构建阶段已完成 Compose 配置解析。
- 这是门店验收候选版本。完成四角色、打印机、扫码/拍照、备份恢复和库存并发验收后再提升为 V1.0.0。
