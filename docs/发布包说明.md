# 打金店管理系统发布包说明

版本日期：2026-09-17

## 目录

- `server/`：上传 Linux 服务器的 Docker 部署文件。
- `client/`：Windows 收银端安装程序。
- `artifacts/`：已构建的后端 JAR、管理端静态文件和移动端 H5 静态文件。
- `docs/`：部署、操作、接口、数据库、测试与手机端打包文档。
- `SHA256SUMS.txt`：关键发布文件的 SHA-256 校验值。

## 推荐部署方式

上传整个压缩包并解压，只需进入 `server/` 按《服务器配置快速指南》执行。`server/` 保留前端源码，是为了让 Docker 在目标服务器按当前版本构建镜像；`artifacts/` 用于留档或自定义 Nginx 部署。

Windows 收银电脑安装 `client/打金店收银台 Setup 1.0.0.exe`，首次启动后配置服务器 API 地址与打印机。
