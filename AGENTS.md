# Agent Configuration

This file configures how AI agents work with this repository.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for this repository. See `docs/agents/issue-tracker.md`.

### Triage labels

使用默认的 triage label vocabulary (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix)。详见 `docs/agents/triage-labels.md`。

### Domain docs

Single-context layout: `CONTEXT.md` at repo root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
